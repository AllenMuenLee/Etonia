# Study Desk navigation and chat sources

- Replace the Chat / Study material switch with Flashcards and Tests directly below New chat in the left panel.
- Each library shows every saved item of its type, with grid and list views, search, creation, and existing item actions. Show ungrouped items first, then class groups. Keep sorting within each group.
- Put the history search icon beside Close history. Keep Close history and Back in the left panel; show only Open history in the main section when the panel is closed. Test and flashcard players use the panel's Back action.
- On a class page, put New test and New flashcards just below the composer with a small top gap, followed by Chats, Tests, and Flashcards tabs.
- Label the sidebar chat history Recent and include all chats regardless of the selected class, while retaining search and pinning.
- Keep chat sources as independent session snapshots. Initialize class chats from class-associated notes and folders only; never collect edits from other chats into those defaults.
- Put sources in a single horizontally scrollable row at the beginning of the chat's scrollable history. Clicking a source opens its first page in the inspection pane; its x removes it. Put Add source on a separate row underneath all attached sources. The add picker cannot remove existing attachments.
- Test creation selects material independently of chat attachments. Debounce topic suggestions, use the existing lightweight Luna model, and ignore suggestions from superseded material selections or dismissed sheets. Allow manual focus and generation if suggestions fail. Send only selected material to test generation and save those source IDs on the paper.
- Difficulty has exactly three button choices: Fundamental, Medium, Hard. Preserve the stored difficulty enum values and their generation instructions.
- Validate source isolation, complete libraries and grouping order, both view modes, selected-material generation, stale topic responses, and phone/tablet/desktop layouts in both themes with enlarged text.
